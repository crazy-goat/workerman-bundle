# Findings — coder, issue #721

## Obstacles and surprises

- **Host is Darwin, but the fix is Linux-only.** The entire ancestry path is gated on `PHP_OS_FAMILY === 'Linux'` and on `/proc`, so it cannot be live-proved on this host; Linux tests are `@requires OS Linux` and are skipped locally (7 skipped). The implementation was verified via `php -l`, `phpstan level 8` (clean after removing a redundant `!== 0` that phpstan flagged as always-true), `php-cs-fixer` (clean), and the 21 non-Linux tests that do run on Darwin. The real proof is CI's Linux legs and the marker-file-based `forkAncestryPair()` helper, which on Linux will create a genuine parent→child hierarchy via a temp script exec'd with the Workerman master title (`exec -a`).
- **Zombie `/proc` availability assumption.** The fix relies on `getParentPid(fingerprint->pid)` still returning the intermediate after `waitForProcessToStop()` has already classified the master as dead (zombie considered not alive). On Linux a zombie retains its `/proc/$pid/status` until the parent reaps; the hung intermediate never reaps, so the entry should still be readable at kill time. If the master had already been reaped (no `/proc` entry), `getParentPid` returns `0` and the ancestry check fails closed — the intermediate leaks once, but no wrong process is killed. This was not probed live in this session.
- **Test helper complexity for a two-level hierarchy.** A plain `pcntl_fork()` makes the test process the parent of the child, not the intermediate. To create `intermediate → master` with the intermediate carrying the Workerman title, the helper forks once from the test, then `pcntl_exec`s a temporary PHP script with `exec -a 'WorkerMan: master process ...' php script.php`; that script forks again (parent = intermediate with title, child = master), communicating PIDs via two marker files waited on with `Wait::until`. The plain-parent variant (shell safety test) execs the same script without the `exec -a` wrapper. Cleanup must handle reparenting (master becomes child of init after intermediate death) and unlink all temp files.
