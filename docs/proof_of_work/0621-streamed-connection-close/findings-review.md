| F-1 | medium | src/Middleware/SymfonyController.php:129-131 | The new `$shouldClose` computation in `SymfonyController::__invoke()` is not tested. `tests/SymfonyControllerTest.php` has `testStreamedResponseE2E` but it uses an HTTP/1.1 request without `Connection: close`, so `$shouldClose` is `false` and the close path is never exercised at the controller level.
